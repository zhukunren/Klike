# 形态镜像 · K 线形态识别

一个基于用户手绘曲线检索相似历史 K 线的本地研究工具。项目直接读取 `data/stock_daily.parquet`，使用收盘价路径做归一化结构匹配，同时返回匹配区间之后的 15 个交易日表现、量能变化和 OHLC K 线。

## 启动

环境要求：Python 3.10+，并已安装 `pyarrow`、`numpy`。

```powershell
python -m pip install numpy pyarrow
python server.py
```

浏览器打开 <http://127.0.0.1:8765>。

## 使用

1. 在左侧画布上按住鼠标或触控笔画出走势。
2. 选择 20 / 40 / 60 日匹配窗口。
3. 点击“搜索相似形态”，从下方结果中选择标的。
4. 中间 K 线图的浅色区域是匹配区间，右侧展示该形态之后的历史表现。

也可以切换到“上传截图”：选择 PNG、JPG 或 WEBP 走势图，系统会在浏览器本地预览图片并自动提取连续走势线。拖动图片上的框选区域可以排除标题、坐标轴和指标面板，提取完成后直接点击“搜索相似形态”即可。图片不会上传到后端或外部服务。

如果上传的是红绿 K 线截图，系统会尝试统计框选区域内的可见 K 线数量，并在“匹配窗口”中增加“截图 · N 根”选项。检测器会结合红/绿像素、垂直跨度和 K 线横向间距去重，均线和细网格线不会直接计数。识别数量可以用加减按钮手动修正，修正后的数量会作为实际匹配窗口提交。截图边缘的半根 K 线、极低分辨率图片和复杂指标面板仍建议通过框选与手动数量修正确认。

搜索模式分为三种：

- 当前候选：只比较每只股票最新的 N 根 K 线，适合生成当前观察名单，不使用未来收益排序。
- 近期形态：在最近 5 / 20 / 60 个交易日内寻找刚形成的相似窗口，越接近最新交易日优先级越高。
- 历史研究：搜索历史最佳相似窗口，并展示该窗口之后的已实现收益。

当前候选和近期形态会额外展示历史相似样本的上涨率、收益中位数和回撤统计，这些数据只用于验证，不代表当前候选的未来收益。页面会显示行情最新日期和数据滞后天数；当前数据文件为日线数据，实际投资使用前应先更新到最新交易日，并补充复权、停牌、风险警示和流动性过滤。

## 市场扫描与观察列表

“市场扫描”是独立的候选工作区，可以按市场范围、扫描模式、最低相似度和状态筛选结果。扫描结果支持星标收藏，点击“查看”会回到形态搜索并打开对应的完整 K 线区间。

“观察列表”保存在当前浏览器的本地存储中，不会上传到服务端。进入后会刷新每个标的的最新价格、当日涨跌、5 日/20 日表现、量能比和最近走势；列表中的标的可以再次打开形态结果或移除收藏。

服务首次执行搜索时会将每只股票最近 320 根日线缓存到内存，后续搜索会直接复用缓存。匹配只比较归一化后的价格路径，不比较价格绝对值。
